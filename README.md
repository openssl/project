# Project

This is the internal repository for the OpenSSL project.
It serves as a hub for tracking the progress of our engineering work,
hosting project management artifacts, discussions, issues, and documents
related to the project management.

This repository does not contain the source code.

* [Development Board](https://github.com/orgs/openssl/projects/20)
* [Proposals](proposals/)


## Proposals

[proposals/](proposals/) holds proposals about infrastructure, tooling and
engineering process, one markdown file per proposal, reviewed and discussed in
a pull request. Proposals are merged whatever their outcome, so that rejected
ones stay findable together with the reasoning behind them.

Design documents for the library itself belong in `doc/designs` in
[openssl/openssl], and policies belong in [general-policies] or
[technical-policies]. See [proposals/README.md](proposals/README.md) for the
full boundary, the header format and the review process.


[openssl/openssl]: https://github.com/openssl/openssl
[general-policies]: https://github.com/openssl/general-policies
[technical-policies]: https://github.com/openssl/technical-policies
